# Parser de C++ escrito em C

> Para disciplina de Linguagens de Programação

## Requisitos para construir o projeto
- `make`;
- `llvm`(`clang`);

## Como construir e rodar
- Para contruir de 
``` bash
make
```
- E para rodar de 
``` bash
./build/cppparser
```

## Argumentos
``` bash
./build/cppparser -f <nome_do_arquivo>
```
